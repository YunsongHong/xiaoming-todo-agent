# 小明 · 中文待办清单智能体

在聊天框里输入「帮我记一下洗衣服」，再说「衣服洗好了」。小明会更新同一条任务。聊天和任务 API 共用本地文件 `data/tasks.json`，刷新页面会清空对话，重启服务后仍能查到任务。

## 本地运行

需要 Node.js 24.12 或更高版本。克隆本仓库后，在项目根目录执行：

```sh
npm ci
npm run dev
```

打开 <http://127.0.0.1:3000>。以下验收步骤均可离线处理，安装依赖后无需模型密钥。

## 六轮验收

从空清单开始，逐行把左栏的消息发给小明。也可以在另一个标签页打开 <http://127.0.0.1:3000/api/tasks>，刷新后核对保存的状态。

| 发给小明         | 应看到的结果                       |
| ---------------- | ---------------------------------- |
| 帮我记一下买牛奶 | 新增「买牛奶」                     |
| 再记一条取快递   | 新增「取快递」                     |
| 我有哪些任务？   | 待办 2 项，已完成 0 项             |
| 牛奶买好了       | 「买牛奶」已完成，「取快递」仍待办 |
| 取快递这条删掉吧 | 删除「取快递」                     |
| 再给我看看清单   | 只剩「买牛奶」，列在已完成组       |

刷新页面或重启服务，再发一次「看看清单」，结果应与最后一行相同。自动化检查使用临时清单：

```sh
npm test
npm run typecheck
npm run lint
npm run build
```

## 还可以怎么用

- **截止日期**　输入「新增明天交报告」或「新增 2027-01-05 交报告」。标题开头的今天、明天、后天和 ISO 日期会存成截止日。「今天有哪些任务到期？」只列当日截止且尚未完成的事项，「有什么逾期的任务」列出已过截止日的待办。相对日期按上海时间计算。
- **重名与简称**　假设清单里有「交周报告」和「交项目报告」。输入「删除报告」后，小明列出两个候选，再回复「第二个」即可删除对应任务。选择绑定到上一轮展示的任务 ID，期间另一条任务被删除也不会引起错位。
- **重复输入**　再次添加标题与截止日都相同的未完成任务，会得到已有提示。已完成的任务可以在新一轮重新添加。
- **可选模型**　复制 `.env.example` 为 `.env`，在本地填写自己的 `DEEPSEEK_API_KEY` 后重启。常见指令走本地解析；遇到其他说法时，只把当轮文本交给 DeepSeek 解析。模型提出的写操作会显示为一条待确认的指令。读取和写入都由服务端完成。

这是本机单用户清单，每次处理一项操作。日期以自然日保存，无定时推送。接口字段与响应见 [OpenAPI](server/openapi.yaml)。
